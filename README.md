# Overview

This repository contains the code used for the paper [In Search of the True Greenium](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4744608) by Eskildsen, Ibert, Jensen, and Pedersen (forthcoming, *Journal of Financial Economics*). Please cite this paper if you are using the code:

```
@article{EskildsenIbertJensenPedersen2026,
    author = {Eskildsen, Marc Baert and Ibert, Markus and Jensen, Theis Ingerslev and Pedersen, Lasse Heje},
    title = {In Search of the True Greenium},
    journal = {Journal of Financial Economics},
    year = {2026}
}
```

Please send questions about the code to Theis I. Jensen at [theis.jensen@yale.edu](mailto:theis.jensen@yale.edu).

A single end-to-end run of the pipeline regenerates every figure and table in the paper and its Internet Appendix.


# How to run the code

Clone this repository to your local machine, set up the two language environments, place the raw data under `data/raw/` (see **Data** below), and run the pipeline.

## Requirements

- **Python 3.13+**, managed with [`uv`](https://docs.astral.sh/uv/) (exact versions pinned in `uv.lock`).
- **R 4.5+**, with packages pinned in `renv.lock` (managed by [`renv`](https://rstudio.github.io/renv/)).
- Roughly **120 GB of free disk** (≈30 GB of raw data plus pipeline intermediates) and **~64 GB of RAM** (the bootstrap steps are the most demanding).

## Environment setup

```bash
# Python
uv sync

# R (renv must be installed system-wide first; activate creates the project
# library, and restore must run in a fresh session so it targets that library)
Rscript -e 'install.packages("renv")'
Rscript -e 'renv::activate()'
Rscript -e 'renv::restore(prompt = FALSE)'
```

## Data

The pipeline reads the raw inputs below. Each must be placed in the indicated
folder under `data/raw/` with the exact filename shown. `data/CHECKSUMS.sha256`
lists every expected file with the SHA-256 hash of the real data used in the paper.

This GitHub repository contains code only (`data/raw/` is git-ignored). The publicly
redistributable inputs — `icc/`, `vilkov_options/`, `hoberg_phillips/`, `ccpi/`, and
`other/` (except `industry_codes.csv` and `crsp_dsenames.csv`) — are deposited on
Mendeley Data as part of the paper's replication package
([doi:10.17632/sv8b78rkps](https://doi.org/10.17632/sv8b78rkps)) and should be
copied into `data/raw/`. The remaining inputs are proprietary and must be
obtained from the providers listed below; pseudo versions of them can be generated
with a script in this repository so that the pipeline runs end to end (see
**Pseudo data**).

- `data/raw/jkp/`
    - `Characteristics.zip` — Global stock returns and firm characteristics.
    - `return_cutoffs.csv` — extreme-return cutoffs used for return winsorization of global stocks.
    - `rf.csv` — risk-free rate.
    - All of these outputs are from [Jensen, Kelly, and Pedersen (2023)](https://onlinelibrary.wiley.com/doi/full/10.1111/jofi.13249) and can be generated by running the code from [github.com/bkelly-lab/ReplicationCrisis/GlobalFactors](https://github.com/bkelly-lab/ReplicationCrisis/tree/master/GlobalFactors).
- `data/raw/icc/`
    - `icc_us.csv`, `icc_comp.csv` — implied cost of capital, US and global.
    - `forward_eps_us.csv`, `forward_eps_comp.csv` — forward EPS forecasts, US and global.
    - All of these outputs are generated by the code at [github.com/theisij/implied-cost-of-capital](https://github.com/theisij/implied-cost-of-capital).
- `data/raw/msci/`
    - MSCI ESG ratings ("ESG Ratings Timeseries Expanded"), annual files 2007–2022 (`.xlsx` / `.csv`).
    - We obtained the data directly from MSCI. Similar data is available at WRDS: [MSCI ESG Ratings for Global Equities (Historical Data)](https://wrds-www.wharton.upenn.edu/pages/get-data/msci/msci-esg-ratings-legacy/msci-esg-ratings-for-global-equities-historical-data/).
- `data/raw/sustainalytics/`
    - `sust_indicator_all.zip`, `sust_legacy.zip`, `sust_ref_data.zip` — Sustainalytics ESG indicators and reference data.
    - `G_NAMES.csv`, `IDS_TABLE.csv` — identifier/name tables.
    - Pulled from WRDS: [Sustainalytics](https://wrds-www.wharton.upenn.edu/pages/get-data/sustainalytics/). The ESG Risk Rating Indicator (`sust_indicator_all.zip`) and Reference Data (`sust_ref_data.zip`) are available there. The Legacy Data (`sust_legacy.zip`) and the underlying `G_NAMES.csv` / `IDS_TABLE.csv` tables appear to no longer be available on WRDS — the latter used to be a category in the WRDS interface but has since been removed.
- `data/raw/trucost/`
    - `trucost.zip` — Trucost firm-level carbon-emissions data.
    - Pulled from WRDS: [Trucost Environmental](https://wrds-www.wharton.upenn.edu/pages/get-data/compustat-capital-iq-standard-poors/trucost/trucost-environmental/environment/).
- `data/raw/morningstar/`
    - `Morningstar_holdings_consolidated.csv`, `Morningstar_holdings_consolidated_notArticle9.csv`, `Morningstar_holdings_consolidated_notArticle9_US.csv` — fund holdings.
    - `Sustainable_Funds_Processed.csv` — sustainable-funds classification.
    - We obtain all funds from Morningstar Direct that have the flags "Morningstar Category Broad Group == Equity" and "Is ESG Intentional Investment - Overall == Yes." Morningstar provides fund characteristics as well as fund holdings. 
- `data/raw/sers/`
    - `subjective_er.csv`, `value_line.csv`, `morningstar.csv` — subjective risk and return expectations from equity analysts.
    - From [Jensen (2026)](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4276760). Underlying data is from I/B/E/S, Value Line, and Morningstar.
- `data/raw/vilkov_options/`
    - `glb_daily.zip` — option-implied data (global daily).
    - `MartinWagnerBounds.zip` — Martin–Wagner expected-return bounds.
    - From [Grigory Vilkov's OSF data repository](https://osf.io/user/8awyu).
- `data/raw/bonds/`
    - `yields_traded_firm.csv` — corporate bond yields by firm.
    - From [Dick-Nielsen, Feldhutter, Pedersen, and Stolborg (2026)](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4586652).
- `data/raw/hoberg_phillips/`
    - `tnic3_data.zip` — Hoberg–Phillips TNIC3 text-based industry network.
    - From [Gerard Hoberg and Gordon Phillips's data library](https://hobergphillips.tuck.dartmouth.edu/tnic_basedata.html).
- `data/raw/ccpi/`
    - `CCPI_data.xlsx` — Climate Change Performance Index country scores.
    - Collected manually from the annual reports on the CCPI [downloads page](https://ccpi.org/downloads/).
- `data/raw/linking/`
    - `WRDS_GVKEY.csv`, `WRDS_ISIN.csv` — WRDS identifier linking tables.
    - Capital IQ identifier tables, downloaded from [WRDS Capital IQ Identifiers](https://wrds-www.wharton.upenn.edu/pages/get-data/compustat-capital-iq-standard-poors/capital-iq/identifiers/identifiers/) (documented in [Linking within Capital IQ](https://wrds-www.wharton.upenn.edu/pages/wrds-research/database-linking-matrix/linking-capital-iq-with-compustat/)).
- `data/raw/other/`
    - `industry_codes.csv` — industry classification codes. Derived from the JKP data set.
    - `ME_Breakpoints.csv` — NYSE size (market-equity) breakpoints. From the [Kenneth R. French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html).
    - `country_abbr.xlsx` — country abbreviations. Ships with this repository (no download needed).
    - `countries.zip` — world country boundaries (Natural Earth, 110m admin-0), used for the map in Figure 13. From [Natural Earth](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/).
    - `gics_names.xlsx` — GICS sector/industry names (sheet "Effective close of Mar 17 2023"). From the [MSCI GICS structure](https://www.msci.com/our-solutions/indexes/gics).
    - `crsp_dsenames.csv` — CRSP daily stock event names file (`dsenames`), used for firm names in Figure 16. From [CRSP via WRDS](https://wrds-www.wharton.upenn.edu/).

## Pseudo data

The proprietary inputs cannot be redistributed. `scripts/make_pseudo_data.py`
generates a synthetic stand-in for every proprietary file: same filenames, zip
members, columns, and types, but random observations drawn from distributions
recorded in `data/pseudo_schema.json` (which contains no identifiers or data values
from the original files). The default universe is 1,000 firms in six countries
over 2005–2022. A pre-generated copy (`raw_pseudo/`) is also included in the
Mendeley Data deposit.

```bash
uv run python scripts/make_pseudo_data.py            # writes data/raw_pseudo/ (~100 MB, ~1 min)
cp -r data/raw_pseudo/* data/raw/                    # alongside the public inputs above
bash run.sh                                          # ≈ 45 min on the pseudo data
```

The run produces every figure and table listed under **List of tables and
programs**, but the numbers will not match the paper. The checksums in
`data/CHECKSUMS.sha256` apply to the real data only.

## Run

```bash
bash run.sh
```

This sources the determinism settings in `scripts/env.sh` and then runs the two pipeline stages:

1. `uv run python -u -m greenium.main` — the main Python pipeline (≈ 3.5 h on a first run; the bootstrap regeneration dominates).
2. `Rscript R/main.R` — the R post-processing (≈ 45 min).

Figures are written to `output/figures/` and tables to `output/tables/`. To reuse cached intermediates instead of regenerating them from scratch, set `FULL_RUN = False` in `greenium/config.py`.
